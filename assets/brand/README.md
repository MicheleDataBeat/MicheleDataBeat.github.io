# DataBeat mark

The orbit: a ring, a core and two nodes, drawn on a 64-unit box. Ring radius 22, stroke 2.4; core radius 9.5; nodes radius 4.5 on the ring at 225° (upper left) and 45° (lower right). Monochrome, no tile: ink #181a1b on the page ground #f7f7f2, or off-white on a dark ground. Below 32 px use the small cut (`mark-small.svg`: stroke 3.2, core 10, nodes 5.2).

- `mark.svg`, `mark-light.svg`, `mark-small.svg` — the mark alone, ink or off-white
- `avatar.svg`, `avatar-1024.png`, `avatar-512.png` — the ink mark on the page ground, for the GitHub profile (GitHub needs an opaque image)
- `../favicon.svg` — the mark alone, ink on light tabs and off-white on dark tabs; `../favicon-32.png` — the mark alone on transparency; `../apple-touch-icon.png` — the mark on the page ground (iOS needs an opaque icon)
